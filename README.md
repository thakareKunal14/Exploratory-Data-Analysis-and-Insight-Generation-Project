# Exploratory Data Analysis (EDA) Project

## 🔹 Project Objective

The objective of this project was to perform in-depth exploratory data analysis to understand the structure, patterns, correlations, and key relationships within the dataset before moving toward predictive modeling.

## 🔹 Data Understanding

- Inspected dataset structure using `df.info()` and `df.describe()`
- Identified numerical and categorical variables
- Checked missing values and data types
- Evaluated data distribution and spread

## 🔹 Data Cleaning & Preparation

- Handled missing values
- Converted text columns into appropriate formats
- Selected numeric columns for correlation analysis
- Ensured data consistency for visualization

## 🔹 Exploratory Analysis Performed

✔ Univariate Analysis

- Distribution plots
- Summary statistics

✔ Bivariate Analysis

- Scatter plots
- Pair plots
- Relationship analysis

✔ Correlation Analysis

- Generated correlation matrix
- Visualized using heatmap
- Identified positive and negative relationships
- Interpreted strength of correlation (-1 to +1)

## 🔹 Key Insights

- Identified moderate to strong positive correlations between key variables.
- Observed patterns indicating relationships between independent variables.
- Highlighted variables with potential predictive importance.
- Detected trends and seasonal patterns.

## 🔹 Visualization Techniques Used

- Heatmaps
- Pairplots
- Scatterplots
- Line charts
- Distribution plots

All visualizations were customized for professional presentation (figure size, color palettes, annotations).
